SkyPulse

SkyPulse is a modern Android weather application built with Kotlin and Jetpack Compose. The app provides current weather information based on a user's location or a searched city.

Features
 Current weather information
 Location-based weather
City search
 Reactive UI using Kotlin Coroutines and Flows
 Type-safe Navigation
 MVVM architecture
 Dependency Injection with Hilt
 REST API integration with Retrofit
 Modern Material 3 UI
Tech Stack
Kotlin
Jetpack Compose
Material 3
Coroutines & Flow
MVVM
Hilt
Retrofit
OpenWeather API
Navigation Compose
